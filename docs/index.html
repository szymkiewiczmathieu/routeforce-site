Latest release

What is new in TourviaApp 7.34.0.1

Released 21 July 2026 on the Security-Review-approved lineage. Details for admins are in the setup guide and the user guide.

  • Current schedules: changing route options invalidates the previous plan before Events are created, preventing stale appointment times.
  • Stable recalculation: a slow response can no longer restore an obsolete route step.
  • Stronger access and data handling: keyboard focus reaches step actions, Agentforce filters recency before limiting results, and optional marker type configuration can no longer hide the map.
